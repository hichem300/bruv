## Acceptance criteria audit

- Adapter contract parity: Simple Jev and TypeSafe adapters pass shared
  `assert_backend_contract` plus exact HTTP/SDK tests.
- stdout/stderr split: JSON and requested field go to stdout; diagnostics to
  stderr.
- Schema validity: `spec`, `schema request|output|error` emit valid JSON with
  `$id` and `version`; snapshots pinned.
- No-call validation/dry-run: `validate` and `--dry-run` never invoke a backend
  transport (guarded by `_NeverCallBackend` and request counters).
- Secret redaction: sentinel `bruv_test_secret_DO_NOT_PRINT` absent from adapter
  exceptions, stdout, stderr, JSON, and doctor results.
- Visible Simple Jev uncalibrated marker: `calibrated: false` in JSON, terminal
  output, demo expected output, and docs.
- Clean wheel: `test_clean_install.py` passes.
- Standalone install: installer contract tests pass; PyInstaller spec and
  build script present.
- Setup/doctor: non-TTY setup exits 2; doctor runs non-paid diagnostics with one
  fix per failed item.
- Bash/PowerShell demo: `run.sh` and `run.ps1` begin with dry-run.
- Skill packaging/install: `SKILL.md` passes standard checks; installer covers
  codex|claude|pi × user|project.
- Agent scenarios: baseline and post-skill scenario files recorded with expected
  behaviors.
- Untrusted PR safety: CI uses `contents: read`, no provider secrets, no live
  API calls, no model downloads.
- Apache detection: `LICENSE` is Apache-2.0; `test_license_is_apache_2` passes.
- README clean-machine path: order matches design; unofficial disclosure
  present; 60-second install first.
- Checksums/SBOM/release notes: release workflow generates SHA256SUMS, optional
  signature, CycloneDX SBOM, and changelog-derived notes.
