# README Terminal GIF Design

## Goal

Create a polished, honest terminal GIF showing bruv installation followed by a real typed decision. Place it below the existing README workflow image.

## Content

The terminal sequence will:

1. Run `pip install bruv`.
2. Accelerate routine installation output while preserving real captured lines.
3. Run a concise Noul refund-classification command against the documented Simple Jev public demo endpoint.
4. Show the real typed decision output for about four seconds.
5. Pause briefly before looping.

No API keys, credentials, fabricated results, or hidden paid calls may appear.

## Visual Design

- Canvas: 1200 × 675 pixels.
- Style: dark terminal with a small orange bruv accent matching the README workflow graphic.
- Duration: approximately 15–20 seconds.
- Output must remain readable at GitHub README width.
- Cursor and typing motion should feel natural without reproducing full installation wait time.

## Implementation

Capture exact command output first. Render that captured text into timed terminal frames with local tooling, then encode and optimize the frames as `docs/assets/bruv-demo.gif`. Use FFmpeg for encoding. Keep generation artifacts outside the repository or remove them after successful output generation.

Update `README.md` so the GIF appears directly below `docs/assets/bruv-how-it-works.png`.

## Verification

- Confirm installation and classification commands ran successfully.
- Confirm captured result matches rendered GIF content.
- Confirm GIF dimensions, duration, looping, and file size.
- Open the GIF to inspect readability and visual integrity.
- Confirm README image path resolves.
- Run repository checks only if generation requires source-code changes; documentation-only changes need path and artifact verification.
