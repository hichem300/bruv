# bruv v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `bruv`, public Apache-2.0 Python CLI exposing one typed-decision contract over TypeSafe Jev and Simple Jev, with safe human onboarding, deterministic agent interfaces, verified standalone installers, and runnable funnel-audit demo.

**Architecture:** CLI handlers construct canonical Pydantic domain models and call `DecisionFacade`. Facade validates against immutable backend capabilities, invokes injected `DecisionBackend`, and returns canonical results or stable application errors. Provider request/response shapes remain inside TypeSafe and Simple Jev adapters; output, gates, schemas, demos, and exit policy consume canonical models only.

**Tech Stack:** Python 3.11+, Typer, Pydantic 2, HTTPX, platformdirs, Rich, PyYAML, pytest, pytest-httpx, Ruff, mypy, build, PyInstaller, GitHub Actions, CycloneDX SBOM.

---

## Scope and sequencing

One repository delivers four independently testable milestones:

1. **Core:** domain, validation, facade, adapters, commands, output, gates.
2. **Agent surface:** `spec`, schemas, offline validation, dry-run, packaged skill, safe skill installer.
3. **Human surface:** setup, doctor, help, funnel-audit demo.
4. **Public release:** policies, CI, standalone artifacts, verified installers, checksums, SBOM, release notes.

No MCP, batch/resume, plugins, model lifecycle management, telemetry, caching, or System One Adapter backend enters v1.

- [ ] **Step 2: Implement one-method port and deep facade**

```python
class DecisionBackend(Protocol):
    capabilities: BackendCapabilities

    def evaluate(self, request: DecisionRequest) -> DecisionResult: ...


class DecisionFacade:
    def __init__(self, backend: DecisionBackend) -> None:
        self._backend = backend

    def validate(self, request: DecisionRequest) -> ValidationResult:
        return validate_request(request, self._backend.capabilities)

    def evaluate(self, request: DecisionRequest) -> DecisionResult:
        validation = self.validate(request)
        if not validation.valid:
            raise RequestValidationError.from_issues(validation.issues)
        return self._backend.evaluate(request)
```

Stable errors: `UsageError`, `RequestValidationError`, `AuthenticationError`, `BackendUnavailableError`, `ProviderResponseError`, `ConfigurationError`. Each exposes `code`, `message`, `paid_request`, `action`, and optional safe `details`.

```python
class TypeSafeJevAdapter:
    capabilities = BackendCapabilities(
        backend="typesafe",
        question_types=frozenset({"noul", "choice", "score"}),
        calibrated=True,
        allows_json_state=True,
    )

    def __init__(self, client: TypeSafeClientPort, model: str | None) -> None:
        self._client = client
        self._model = model

    def evaluate(self, request: DecisionRequest) -> DecisionResult:
        provider_questions = {
            key: self._to_provider_question(question)
            for key, question in request.questions.items()
        }
        response = self._client.system_one(
            state=request.state,
            questions=provider_questions,
            model=request.model or self._model,
        )
        return self._to_result(response)
```
